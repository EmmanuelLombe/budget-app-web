# Budget App

A web budgeting app that splits your income into buckets and tracks spending against each one.

**Live demo:** https://budget-app-web-nine.vercel.app/

**GitHub repo:** https://github.com/EmmanuelLombe/budget-app-web/tree/main

> Screenshot coming soon.

## Tech Stack:

React, TypeScript, Vite, Tailwind CSS, React Router, Zustand, Vitest.

## Run locally:

    npm install
    npm run dev

## Status:

In development. The design system and layout are live. Income, expense and dashboard screens are being built.
